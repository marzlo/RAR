⏰ PM 待辦原則上當天處理完。下面是兩種最常見情況的處理流程。

① 同步 STLA / Jira 回覆

STLA 在 RTC 回覆
狀態：Solution Proposed 或 RAR Rejected
↓
PM：把 STLA 的回覆貼到 Jira，再 Assign 給 RD
↓
RD：在 Jira 回覆對 STLA 回覆的看法
↓
PM 判斷：RD 接受嗎？
✔ RD 接受
在 RTC 票上
  1. 留言：solution accepted
  2. Solution Proposed：Solution Proposed → Accept solution → Closed
  3. RAR Rejected：保持原樣
↓
在 Jira 票上：狀態切成 Done
↺ 需要再跟 STLA 溝通
在 RTC 票上
  1. 把 RD 的問題從 Jira 複製貼到 RTC 票
  2. Solution Proposed：Solution Proposed → Reject solution → Draft → Submit
  3. RAR Rejected：RAR Rejected → Draft → Submit
↓
等 STLA 再次回覆 → 回到流程最上面

② 建 RTC 票

  1. 打開任一張 RTC ticket，按右上角的 Create Work Item Copy 建立新票（圖一）。
    圖一
  2. 把 Jira 的 Summary 貼到 RTC 的 Summary。
  3. 填入對應的欄位（圖二紅框）：
    • Other Specification / Document ID
    • Stellantis Requirement ID（Req ID）
    • Owned By：Antoniel Peixoto
    圖二
  4. 把 RD 的問題貼在 Description。
  5. 存檔後，把 RTC 票的連結貼回 Jira 的 External Link。
⏰ PM to-do items should be done the same day. Below is the flow for the two most common cases.

① Sync the STLA / Jira reply

STLA replies in RTC
Status: Solution Proposed or RAR Rejected
↓
PM：copy the STLA reply into Jira, then assign it to RD
↓
RD：answers in Jira about the STLA reply
↓
PM decides: does RD accept?
✔ RD accepts
In the RTC ticket
  1. Comment: solution accepted
  2. Solution Proposed：Solution Proposed → Accept solution → Closed
  3. RAR Rejected：leave as is
↓
In the Jira ticket：set the status to Done
↺ Needs more discussion with STLA
In the RTC ticket
  1. Copy RD's question from Jira into the RTC ticket
  2. Solution Proposed：Solution Proposed → Reject solution → Draft → Submit
  3. RAR Rejected：RAR Rejected → Draft → Submit
↓
Wait for STLA to reply again → back to the top

② Create the RTC ticket

  1. Open any RTC ticket and click Create Work Item Copy at the top right (figure 1).
    Figure 1
  2. Paste the Jira Summary into the RTC Summary.
  3. Fill in the matching fields (red boxes in figure 2):
    • Other Specification / Document ID
    • Stellantis Requirement ID（Req ID）
    • Owned By：Antoniel Peixoto
    Figure 2
  4. Paste RD's question into Description.
  5. Save, then paste the RTC ticket link into the Jira External Link.
